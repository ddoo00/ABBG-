휴무일 관리

ABBG 휴무일이에요. 납기 선택과 스케줄에 반영되고, ABBG 관리 화면에서 등록해요.

사용 가이드
업무 요청 전 아래 안내사항을 꼭 확인해주세요
업무 요청 전 필독 안내
1
요청 시 작업 기간도 함께 고려해주세요. 실제 착수까지 1~2일 정도의 준비 기간이 필요합니다.
2
업무 요청 전 스케줄 탭에서 구독 1·2 일정을 먼저 확인해주세요. 기존 일정과 충돌 여부를 고려하여 요청 부탁드립니다.
3
소스를 업로드한 드라이브 링크도 함께 공유해주세요. 누락될 경우 작업이 지연될 수 있습니다.
4
수정 요청 시 한 파일로 정리하여 전달해주세요.
5
급건은 하루에 처리 가능한 건수가 제한적이에요. 등록 시 뜨는 일정 조율 안내를 확인하시고, 급한 건은 카톡방으로도 편하게 말씀해주세요.

완료 처리
1
요청서 작성
요청자, 작업 유형, 납기일, 작업명, 우선순위, 드라이브 경로를 입력하세요.
2
일정 조율 알림
납기가 촉박하거나 드라이브 링크가 없으면, 또는 그 날 급건이 몰려 있으면 등록 전 경고와 추천 마감일이 자동으로 떠요.
3
ABBG 전용
검토 · 확정
요청이 들어오면 구독을 배정하고 확정 납기일 입력 후 승인하세요.
4
스케줄 확인
확정된 작업은 진하게, 검토 대기 중인 요청은 흐리게 구분돼요. 작업명 앞 체크 버튼으로 완료 처리, 날짜 위 복사 아이콘으로 그 날 마감 목록을 바로 복사할 수 있어요.
5
담당자 · 휴무일
담당자 추가 및 회사 휴무일을 직접 등록하면 납기 선택에서 자동으로 막혀요.
6
드라이브 경로 필수
요청 내용란에 네이버웍스 드라이브 경로를 항상 함께 적어주세요.
7
완료 처리 & 실행취소
요청 현황·검토 탭 카드의 "완료 처리" 버튼 한 번이면 끝. 잘못 눌렀다면 화면 아래 토스트의 "실행취소"를 바로 눌러주세요.
8
진행중 · 완료 필터
확정 작업이 많아지면 목록 상단 필터로 진행중·완료·전체를 구분해서 볼 수 있어요.
공휴일 자동 차단
법정공휴일과 대체공휴일은 납기일 선택이 자동으로 막혀요.
일정 과부하 경고
해당 날짜 마감 건이 3건 이상이면 자동으로 경고가 떠요.
급건 캐파 초과 표시
급건이 하루 처리 캐파를 넘으면 간트차트에 표시되고 추천 마감일을 안내해요. 날짜 위 복사 아이콘으로 마감 목록도 바로 복사할 수 있어요.
소요일 가이드
작업 유형을 고르면 예상 소요일과 기준 분량을 안내하고, 희망 납기일을 소요일 기준으로 채워줘요.
실시간 반영
다른 사람이 요청을 올리거나 완료 처리하면 새로고침 없이 화면에 바로 반영돼요.
삭제 전 한 번 더 확인
작업·담당자·휴무일 삭제는 실수 방지를 위해 확인 창을 한 번 더 거쳐요.
ABBG 전용 메뉴예요
검토·확정은 ABBG 팀원만 접근할 수 있어요.
